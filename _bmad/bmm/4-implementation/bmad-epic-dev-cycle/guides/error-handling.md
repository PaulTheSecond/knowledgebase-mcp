# Правила обработки ошибок

## DEV: Блокировка разработки

### Условия блокировки

- Требуются неутвержденные зависимости
- Неоднозначность после проверки истории
- 3 неудачные попытки реализации/исправления
- Отсутствует конфигурация
- Регрессия в тестах

### Действие

**HALT** и уведомить пользователя о причине блокировки

---

## QA: Отклонение истории

### Максимальное количество reopens

`max_reopens: 3`

### При достижении лимита

**Действие:** ESCALATE

**Сообщение:** "История {story} отклонена {N} раз. Требуется ручной анализ."
