- (decision) Stakes set to Internal Team. Working mode: Coaching path. Deliverables: Architecture Spine, Solution Design, and C4 Diagrams.
- (decision) AD-1: Separate processes for MCP stdio and Webhook/Dashboard daemon, sharing a single SQLite file with WAL mode enabled.
- (decision) AD-2: Global service status is stored in a SQLite 'system_status' table. Worker checks this table at startup; if 'halted', it pauses processing. Task idempotency is guaranteed by comparing the current Git SHA against the last indexed Git SHA.
- (decision) AD-3: Auth for WebSockets and SSE uses signed short-lived tokens in query string. WebSockets used for Dashboard telemetry; SSE used for RAG Chat streaming.
- (decision) AD-4: Git tokens (PAT) are never stored on disk in repository config files. They are passed dynamically using Git's http.extraHeader configuration option during runtime.
