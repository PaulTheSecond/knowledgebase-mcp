# Knowledge Review Plugin

Плагин для Antigravity и Claude Code, обеспечивающий автоматизированное архитектурное и дефектное код-ревью с использованием Knowledge Base MCP (`knowledge-mcp`).

## Возможности
- **Многорепозиторный анализ**: автоматическое обнаружение всех связанных репозиториев задачи (frontend, backend, e2e-tests).
- **Blast Radius**: построение графа зависимостей и выявление затронутых компонентов во всем коде.
- **Покрытие тестами и Test Gaps**: сопоставление unit- и транзитивных E2E-тестов с измененным кодом.
- **Аудит чек-листов качества**: автоматическая проверка специфичных проектных правил (.kb).
- **Прозрачный риск-скоринг**: математический расчет уровня риска изменения.

## Состав плагина
- `mcp_config.json`: конфигурация подключения к серверу базы знаний (порт 8000).
- `skills/kb-review/SKILL.md`: регламент и пошаговый процесс ревью для агентов.

## Быстрый старт
В чате с ассистентом введите:
```
/review ORBIT-2045
```
или
```
Проведи ревью ветки feature/ORBIT-2045/develop
```
