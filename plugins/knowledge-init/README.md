# Knowledge Init Plugin

Плагин для Antigravity и Claude Code, обеспечивающий автоматизированную инициализацию репозиториев и воркспейсов в базе знаний Knowledge Base MCP (`knowledge-mcp`).

## Возможности
- **Автоматический аудит структуры**: распознавание одиночных репозиториев, монорепо и воркспейсов с ворктри.
- **Детекция языков**: C# (.NET/Roslyn), TypeScript/JavaScript (Babel AST), Python (Tree-sitter), Go, Rust.
- **Генерация конфигурации**: корректная запись в `data/config.yaml`.
- **Запуск первичной индексации**: CAS-хранилище, AST-граф связей и эмбеддинги.
- **Интеграция пресетов**: настройка MCP-сервера и реактивных хуков для Claude Code и Antigravity.

## Использование
В чате с ассистентом введите:
```
/init-kb
```
или
```
Подключи текущий репозиторий к базе знаний knowledge-mcp
```
