# Knowledge Base MCP Plugin (`knowledge-base`)

Официальный плагин для Antigravity и Claude Code, объединяющий возможности локальной базы знаний, многорепозиторного код-ревью и онбординга воркспейсов.

## Включенные скиллы (Skills)
1. **`kb-review`**:
   - Автоматическое выявление затронутых репозиториев (backend, frontend, e2e-tests).
   - Расчет радиуса влияния (Blast Radius) и сопоставление тестов.
   - Проверка чек-листов качества (.kb) с отсевом master-легаси.
   - Формирование отчета с диапазонами коммитов и прозрачным риск-скорингом.
2. **`kb-init`**:
   - Автоматическое обнаружение структуры проектов и языков.
   - Регистрация в `data/config.yaml`.
   - Запуск первичной индексации CAS/AST/векторов.
   - Настройка MCP-сервера и реактивных хуков для агентов.

## Быстрый старт
```bash
# Установка плагина через маркетплейс репозитория
/plugin install knowledge-base@kb
```

## Доступные команды
- `/review ORBIT-2045` или `/kb-review` — запуск ревью задачи.
- `/init-kb` или `/kb-init` — подключение воркспейса к базе знаний.
